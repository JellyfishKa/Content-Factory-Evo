# Тестовые входные данные

В этой папке лежат файлы для тестирования первой стадии конвейера (`planner.py`).

1. **transcript.txt** — транскрипт внутреннего обсуждения архитектуры конвейера. Содержит разговорную лексику, объяснение «зачем это нужно» и технические детали реализации (валидаторы, Docker, лимиты). Идеален для проверки N=3 сценариев.
2. **article_source.md** — структурированная статья про агентные воркфлоу. Позволяет проверить, как планировщик выделяет разные паттерны (Reflection, Planning и т.д.) в отдельные материалы.
