# Папка референсов

Все файлы в этой папке используются стадией `editor` для контроля качества.

- **Формат:** Строго Markdown (.md).
- **Использование:** При запуске `run_editor` агент считывает содержимое всех файлов в этой папке и использует их как контекст "правильного стиля".
- **Как менять:** Чтобы изменить "голос" всего конвейера, достаточно отредактировать эти файлы или добавить новый пример удачной статьи.
