# Референс структуры: списки и акценты

Проблема «монолитного промпта» решается через разделение на 3 этапа:
1. **Планирование** — выделение тем.
2. **Исследование** — сбор фактов.
3. **Написание** — сборка черновика.

Таблицы используются для прямого сравнения «было — стало», если это уместно для темы. Каждая таблица сопровождается коротким выводом.

Никаких вводных конструкций вроде «в заключение хочется сказать». Последнее предложение — это сухой остаток или ссылка на код/репозиторий.
